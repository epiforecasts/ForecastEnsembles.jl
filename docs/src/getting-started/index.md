## A first example

Wrap component forecasts in a [`ForecastTable`](@ref) and combine them with an
[`EnsembleMethod`](@ref):

```@example
using ForecastEnsembles, DataFrames

df = DataFrame(
    location = "A", horizon = 1,
    model_id = repeat(["m1", "m2", "m3"], inner = 2),
    output_type = "quantile",
    output_type_id = repeat([0.25, 0.75], 3),
    value = [1.0, 3.0, 2.0, 4.0, 0.5, 2.5]
)

ft = ForecastTable(df; task_id_cols = [:location, :horizon])
combine(ft, QuantileEnsemble(:mean))
```

The [Methods](@ref) page explains the two axes — combination operation and
weighting scheme — that organise the available ensembles.
