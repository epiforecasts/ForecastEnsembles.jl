# Package index

## Ensemble methods

Drop-in equivalents to the user-facing functions in `hubEnsembles`,
`qrensemble`, and `lopensemble`. All numerical work runs in Julia.

- [`simple_ensemble()`](simple_ensemble.md) : Hub-style simple/weighted
  ensemble
- [`linear_pool()`](linear_pool.md) : Linear opinion pool
- [`qra()`](qra.md) : Quantile Regression Averaging
- [`crps_weights()`](crps_weights.md) : CRPS-stacked ensemble weights
- [`mixture_from_samples()`](mixture_from_samples.md) : Mixture from
  samples using fitted CRPS weights

## Setup

- [`julia_setup()`](julia_setup.md) : Initialise the Julia bridge
